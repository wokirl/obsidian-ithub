## Введение в компьютерные сети


|    Уровень    |                               |
| :-----------: | :---------------------------: |
|  Физический   |         Кабель, радио         |
|   Канальный   |        Ethernet, WI-FI        |
|    Сетевой    |              IP               |
| Транспортный  |            TCP/UDP            |
|   Сеансовый   |          куки и т.д.          |
| Представление | кодировка, шифрование, сжатие |
|  Прикладной   |        http, dns, smtp        |

| ПРОТОКОЛ | ПОРТ      |
| :------: | :-------: |
|   HTTP   | 80        |
|  HTTP's  | 443       |
|   DNS    | 53        |
|   SSH    | 22        |
|   SMTP   | 25 / 587  |
|   IMAP   | 143 / 993 |
|   FTP    | 21        |
