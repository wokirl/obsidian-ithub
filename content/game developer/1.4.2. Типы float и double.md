## 1. Назначение float и double

В C# существуют два основных типа для хранения чисел с плавающей точкой:

- `float` — числа с плавающей точкой одинарной точности.
    
- `double` — числа с плавающей точкой двойной точности.
    

Оба типа позволяют хранить дробные числа, но отличаются размером и точностью.

|Характеристика|`float`|`double`|
|---|---|---|
|Размер|32 бита|64 бита|
|Объём памяти|4 байта|8 байт|
|Точность|примерно 6–9 значащих цифр|примерно 15–17 значащих цифр|
|Суффикс литерала|`f`|Не требуется|

Пример:

```
float movementSpeed = 5.5f;
double distance = 125.75;
```

**Важно:** `double` не обеспечивает абсолютную математическую точность. Он также хранит приближённые значения, но обычно позволяет представлять их точнее, чем `float`.

## 2. Суффикс f

В C# дробный числовой литерал без суффикса по умолчанию имеет тип `double`.

Например:

```
double distance = 5.5;
```

Если необходимо создать литерал типа `float`, используется суффикс `f`:

```
float movementSpeed = 5.5f;
```

Следующий код вызовет ошибку:

```
float movementSpeed = 5.5;
```

Причина: `5.5` имеет тип `double`, а неявное преобразование из `double` в `float` не разрешено, поскольку оно может привести к потере точности.

**Суффикс** `**f**` **определяет тип самого литерала**, а не выполняет явное приведение уже существующего значения.

## 3. Что такое точность

Точность — способность числового типа представлять значения с минимальной погрешностью.

Например:

$$ 
\frac{1}{3}=0.333333333333\ldots  
$$

У этого числа бесконечное количество цифр после запятой.

Компьютер не может хранить бесконечную последовательность цифр в ограниченном количестве битов.

Поэтому он сохраняет приближённое значение.

При этом точность — не количество знаков после запятой, а количество значащих цифр, которые можно представить с приемлемой точностью.

## 4. Почему возникает погрешность

Компьютер использует двоичную систему счисления.

Некоторые числа, которые легко представляются в десятичной системе, в двоичной системе имеют бесконечную периодическую запись.

Например:

$$ 
0.1_{10}=0.00011001100110011\ldots_2  
$$

Здесь последовательность `0011` повторяется бесконечно.

Поэтому число `0.1` невозможно точно представить стандартным двоичным форматом с плавающей точкой.

Компьютер сохраняет ближайшее представимое значение.

### 4.1. Почему компьютер не может сохранить всю последовательность

Количество битов для хранения числа ограничено.

Если последовательность бесконечна, она не помещается целиком в доступное пространство.

Компьютер не зависает и не пытается вычислить бесконечную последовательность. Он использует ограниченное представление и округляет значение по установленным правилам.

### 4.2. Погрешность при сложении

Рассмотрим:

```
float a = 0.1f;
float b = 0.2f;

Console.WriteLine(a + b);
```

Математически:

$$  
0.1+0.2=0.3  
$$

Однако фактически складываются приближённые представления исходных чисел.

Поэтому результат тоже может содержать погрешность.

## 5. Накопление погрешности

Рассмотрим пример:

```
float playerPosition = 0.1f;

for (int i = 0; i < 10; i++)
{
    playerPosition += 0.1f;
}
```

Математически ожидаем:

$$  
0.1\cdot10=1.0  
$$

Но в действительности при каждой операции происходит следующее:

1. Используется уже приближённое значение.
    
2. Выполняется сложение.
    
3. Результат округляется до ближайшего представимого значения `float`.
    
4. Новое значение используется в следующей итерации.
    

Таким образом, погрешность может накапливаться.

**Важное уточнение:** погрешность не обязательно увеличивается при каждой операции. Она может увеличиваться, уменьшаться или компенсироваться. Однако многократные вычисления способны привести к заметному отклонению.

## 6. Разница между точностью представления и точностью вычисления

Это два взаимосвязанных, но разных понятия.

**Точность представления** — насколько близко сохранённое значение к исходному числу.

**Точность вычисления** — насколько близко результат операции к математически точному результату.

Точность представления влияет на точность последующих вычислений.

## 7. Влияние величины числа на точность

Одна из важных особенностей `float` — расстояние между соседними представимыми числами зависит от величины самого числа.

При увеличении числа расстояние между соседними представимыми значениями тоже увеличивается.

Например, для `float`:

|Величина числа|Расстояние между соседними значениями|
|---|---|
|Около 1|0.0000001192|
|Около 1 000 000|0.0625|

Это означает, что в районе миллиона невозможно точно отразить некоторые очень маленькие изменения координаты.

### 7.1. Пример из разработки игр

Представим персонажа в огромном открытом мире:

```
float playerPosition = 1000000f;

playerPosition += 0.01f;
```

Мы хотим переместить персонажа на `0.01`.

Но расстояние между соседними представимыми значениями `float` в этой области составляет `0.0625`.

Поэтому изменение на `0.01` может вообще не изменить координату.

Это может привести к проблемам с точностью позиционирования.

## 8. Применение в игровой разработке

### float

Часто используется для:

- координат игровых объектов;
    
- скорости передвижения;
    
- физических вычислений;
    
- анимации;
    
- игровых параметров.
    

### double

Может использоваться для:

- научного моделирования;
    
- высокоточных математических вычислений;
    
- расчётов, где требуется большая числовая точность;
    
- систем с очень большими числовыми диапазонами и требованиями к точности.
    

Выбор зависит от требований конкретной системы.

**Важно:** `double` не всегда лучше `float`. Он занимает вдвое больше памяти и не устраняет погрешности полностью.

## 10. Принципы, вызвавшие наибольшее количество вопросов

### Принцип 1. Рациональное число может иметь бесконечную двоичную запись

Число `0.1` рациональное:

$$  
0.1=\frac{1}{10}  
$$

Но в двоичной системе оно имеет бесконечную периодическую запись.

### Принцип 2. Компьютер не хранит бесконечную последовательность

Количество битов ограничено. Поэтому сохраняется ближайшее представимое значение.

### Принцип 3. Погрешность может переходить в следующие вычисления

Приближённое значение используется в последующих операциях, а результаты снова округляются.

### Принцип 4. Большие координаты снижают доступную точность малых изменений

Чем больше величина числа, тем больше расстояние между соседними представимыми значениями.

### Принцип 5. Больше битов не означает абсолютную точность

`double` предоставляет более высокую точность, чем `float`, но также имеет ограничения.
